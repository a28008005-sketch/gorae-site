# 고래영어 초전캠퍼스 홈페이지

경남 진주시 초전동 고래영어학원의 소개 홈페이지입니다.
노션에 글을 쓰면 블로그에 자동으로 올라갑니다.

## 파일 구성

```
site/index.html      소개 홈페이지 (색·글꼴·사진이 이 파일 하나에 다 들어있습니다)
site/img/            사진 원본
tools/blog/          노션에서 글을 받아 블로그를 만드는 프로그램
.github/workflows/   자동 배포 설정
```

## 블로그는 이렇게 돌아갑니다

1. 노션 **고래영어 블로그** 표에 글을 씁니다
2. 상태를 `공개`로 바꿉니다
3. 매일 아침 6시에 홈페이지에 반영됩니다
   (바로 반영하려면 Actions 탭 → 홈페이지 배포 → Run workflow)

자세한 사용법은 [tools/blog/사용법.md](tools/blog/사용법.md)를 봐주세요.

## 미리 보기

```
node tools/blog/build.mjs     # 노션 열쇠가 없으면 예시 글로 만듭니다
```

만들어진 `site/index.html`을 브라우저로 열면 됩니다.
